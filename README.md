# text_tools_project
## Topic: A computational analysis of mean length of utterances MLU and verb morphology Errors in child L2 English ( The Paradis Corpus)
This project uses UNIX shell scripting and python to analyze longitudinal speech Transcripts from the CHILDES English-L2 paradis corpus across five collection rounds. it tracks developmental trajectories in synctactic complexity via MLU in morphemes alongside grammatical error reduction in verb tense and agreement morphology.
